# go-db-cli

Консольное CRUD-приложение на Go для управления базой данных людей (SQLite). Позволяет добавлять, искать, редактировать и удалять записи через простое текстовое меню, а также смотреть базовую статистику по данным.

## Возможности

- **Добавление записи** — ввод имени, возраста и города через консоль
- **Просмотр всех записей** — вывод полного списка людей из базы
- **Поиск** — по имени, возрасту или городу (на выбор)
- **Редактирование** — изменение имени, возраста или города у существующей записи (поиск по текущему имени)
- **Удаление** — удаление записи по имени
- **Статистика**:
  - количество людей в базе
  - средний возраст
  - максимальный возраст
  - минимальный возраст

Всё управляется через интерактивное меню в терминале — программа работает в цикле до выбора пункта "Выход".

## Стек

- **Go**
- **SQLite** — через драйвер [`modernc.org/sqlite`](https://pkg.go.dev/modernc.org/sqlite) (чистая Go-реализация SQLite без зависимости от CGO, поэтому проект собирается без установки системных C-библиотек)
- Стандартный пакет `database/sql`

## Структура базы данных

При первом запуске автоматически создаётся таблица `people`, если её ещё нет:

```sql
CREATE TABLE IF NOT EXISTS people(
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT,
    age INTEGER,
    city TEXT
);
```

База хранится в файле `people.db`, который создаётся автоматически рядом с исполняемым файлом при первом запуске.

## Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/TheOracleCorporation/go-db-cli-.git
cd go-db-cli-

# Установить зависимости
go mod tidy

# Запустить
go run main.go
```

Требования: установленный Go (версия 1.20+ рекомендуется).

## Пример использования

После запуска программа выводит меню:

```
1.Добавить человека
2.Показать всех людей
3.Найти человека
4.Изменить параметр человека
5.Удалить человека
6.Показать статистику
7.Выход
```

Пример добавления записи:

```
1.Добавить человека
Ваше имя:
Иван
Ваш возраст:
25
Ваш город:
Москва
Пользователь успешно добавлен
```

Пример просмотра статистики:

```
6.Показать статистику
1.Сколько людей в базе
2.Средний возраст людей в базе
3.Максимальный возраст человека в базе
4.Минимальный возраст человека в базе
5.Выход из статистики
```
